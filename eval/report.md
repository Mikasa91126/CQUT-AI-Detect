## 一、结论先说

- 默认 `balanced` 模式阈值 **0.007**，
  在**域外**测试集上：Acc **0.929**、
  AUC **0.995**、
  人类样本误判率(FPR) **0.165**、
  AI 漏判率(FNR) **0.000**。
- 这个数字**不能**直接当成「这篇论文被判 AI 的概率」。原因见第四节：语料是 GPT-3.5 时代的
  中文问答，不是学位论文；检测器对「训练分布内」的文本更敏感。
- 工具里真正的护栏是**段落级分歧 + 置信区间 + 明确的不可靠提示**，而不是单看整篇百分比。
- **可操作结论**：本报告数字只适用于**同一分布内的相对比较**；真实中文论文场景请以
  `report` 输出里的**段落相对高低 + 护栏提示**为参考，不要把绝对百分比当作结论。
- **验收门槛（域外测试集 / balanced 阈值）**：**未全部达标**。AUC 0.995 ≥0.85 达标；Acc 0.929 ≥0.80 达标；FPR 0.165 ∉ [0.03, 0.08]（未达标）；Brier 0.018 ≤0.22 达标；各域 AUC 最低 0.986（nlpcc_dbqa） ≥0.75 达标。目标 FPR 未在域外守住：strict 7.2% / balanced 16.5% / lenient 21.4%（目标 1% / 5% / 10%）——按协议未调阈值凑指标，成因与诊断见第七节。 诊断只做消融/正则化/域分离检查，**未通过调阈值或改测试集**规避。
- **用法建议**：重要/高风险场合请用 `--mode strict`（本报告域外 FPR 6.55%）；更稳妥的是先用
  **你自己的正常文本**（与待测文档同文体）重标定，再参考段落相对高低；输出**不可作为学术不端处分的
  唯一证据**。

## 二、方法与数据（可复现）

- 语料：Hello-SimpleAI/HC3-Chinese，HC3 为 GPT-3.5 时代的中文问答语料，与学位论文/学术写作存在领域与时代差异；test 为域名留出，未参与拟合。
- 标定集（参与拟合）：`finance,law,medicine`，单元数 1135
- 测试集（**域外留出，未参与拟合**）：`open_qa,baike,psychology,nlpcc_dbqa`，单元数 1417
- 切分：每条回答按工具同一套 `build_doc` / `make_units` 流程切片，保证特征口径与真实使用一致。
- 融合：三引擎（判别器 / 困惑度 / 文体统计）共 13 个特征 →
  标准化 → 逻辑回归 → 温度缩放（T=0.707）。
- 阈值：在标定集的**人类样本**上按分位数取，使误判率贴近目标值
  （strict 1% / balanced 5%
  / lenient 10%）。
- 规模推算（依据 T1 实测吞吐 `out/smoke.json`）：`--limit 150` → 标定集 1135 单元 / 域外测试集 1417 单元，估算输入字符约 457K。
  实测单单元 clf 0.1209 s + ppl 0.4918 s ≈ 0.6127 s/单元、≈ 2.2392 ms/字；据此推算 calibrate 约 13–17 分钟，bench 复评约 8–10 分钟，合计约 21–27 分钟。
  选择该 limit 的理由：lead 决策 --limit 150：n_dev=1135≥600、n_test=1417≥1200 两门槛均满足，再大（200/300）wall-clock 超预算；相比 120 则 n_test 不足 1200。

## 四、必须说清的四件事（局限）

1. **域偏移**：评测语料是中文问答/百科/情感类短文，而实际要测的是学位论文、报告等长文。
   工具在长文上的表现取决于「论文语料是否落在检测器训练分布内」，这一点无法用公开数据完全验证。
   所以报告里给的是**段落级证据 + 区间**，请按「哪几段可疑」而不是「整篇百分之几」来用。
2. **时代偏移**：HC3 的 AI 文本来自 GPT-3.5（2022）。更新的模型（GPT-4 级、DeepSeek 等）
   输出更接近人类，召回率会下降。检测器对 AI 文本的敏感性 = 我们在「已知 AI 文本」上的召回，
   不等于对「未知新模型」的召回。
3. **误判风险**：人类样本误判率即便只有 16.5%，在 50 段的长文里也意味着
   平均约 8.3 段会被标红。**不要把本工具的输出当作学术不端指控证据**；
   它适合自查、定位可改写段落。
4. **分布乐观性（最重要）**：HC3-Chinese 同时是本项目 clf 判别器的训练语料来源；本报告的「域外测试集」
   只是 HC3 **内部**的域划分（测试域未参与拟合），并非真实场景的分布外样本。T1 smoke 中同源文本上
   clf 对 AI / 人类文本的分数差（gap）在 120 / 900 / 3000 字三档分别为 0.9999 / 0.9998 / 0.9997，
   属于同分布红利。**真实中文论文场景的 Acc/AUC 会明显低于本报告数字**，请勿把上表当作泛化能力证明。

## 七、诊断记录

### 1. 验收门槛判定（域外测试集，阈值由标定集 dev 人类样本按目标分位取得）

| 模式 | 目标 FPR | 域外实测 FPR | Acc | AUC | Brier | 判定 |
|---|---|---|---|---|---|---|
| strict | 1% | 6.55% | 0.9711 | 0.9930 | 0.0168 | FPR 未达标 |
| balanced | 5% | 13.09% | 0.9435 | 0.9930 | 0.0168 | FPR 未达标 |
| lenient | 10% | 19.80% | 0.9146 | 0.9930 | 0.0168 | FPR 未达标 |

- AUC≥0.85、Acc≥0.80、Brier≤0.22、各域 AUC≥0.75 均达标（各域 AUC 0.979–1.000）。
- **FPR 三项均未达标**（目标 1% / 5% / 10%，实测 6.55% / 13.09% / 19.80%）。按「dev 取阈、test 只测不改」协议，**未调阈值、未改测试集、未用 test 选参**。

### 2. 诊断①特征消融（去掉 ppl_rel / burst_rel 后 dev 重新拟合，C=0.5）

- 域外 test：Acc 0.9442 / AUC 0.9929 / FPR 0.1277 / FNR 0.0012 / Prec 0.9117 / Brier 0.0170；T=0.711，阈值 0.0107。
- 与全特征（Acc 0.9435 / AUC 0.9930 / FPR 0.1309 / Brier 0.0168）差异均 < 0.01，FPR 仍远超目标 ⇒ **不是个别特征造成的误判**，去掉 ppl_rel/burst_rel 不能修正迁移偏差。

### 3. 诊断②正则化强度 C 网格（全特征，dev 重新拟合）

| C | test Acc | test AUC | test FPR | test Brier |
|---|---|---|---|---|
| 0.1 | 0.9450 | 0.9934 | 0.1277 | 0.0145 |
| 0.5（标定采用） | 0.9435 | 0.9930 | 0.1309 | 0.0168 |
| 1.0 | 0.9428 | 0.9929 | 0.1326 | 0.0178 |

- C 不改变 FPR 迁移偏差（0.128–0.133）；C=0.1 的 Brier 略好，但按协议**不在 test 上选参**，保持标定时的 C=0.5。

### 4. 诊断③ DEV / TEST 域分离检查

- dev 域 `['finance', 'law', 'medicine']`、test 域 `['baike', 'nlpcc_dbqa', 'open_qa', 'psychology']`，交集为空；与 `calibrate.DEV_DOMAINS` / `calibrate.TEST_DOMAINS` 常量一致 ⇒ **无域混用、无标签泄漏**。

### 5. 成因判断：阈值迁移偏差（域漂移），不是分类器失效

- 误判集中在 nlpcc_dbqa（balanced FPR 37.5%）与 baike（13.8%），open_qa 2.6%、psychology 0.6%。标定域（金融/法律/医学）的人类回答文体与问答/百科/心理学文本不同，dev 人类分数分布更靠左，5% 分位取出的阈值 0.0087 迁到 test 后人类误判 13.1%。
- AUC 0.993 说明**排序区分度正常**，偏的是阈值绝对位置。在不使用 test 选参的前提下无法消除，按 lead 裁定接受为「已记录的不达标」。

### 6. 四档边界倒挂修复（产品侧 `fusion.grade_cutoffs_for`，与标定数值解耦）

- 原公式 `high=t+0.25 / mid_high=t+0.02 / mid=max(0.10, t-0.15)` 在 t=0.0087 时得到 high=0.2587 / mid_high=0.0287 / mid=0.10 → **mid 反超 mid_high，四档倒挂**（报告图例/上色会错乱）。
- 修复：线性偏移失效时改按比例缩放 `high=4t / mid_high=t / mid=0.5t`；未标定大阈值（t=0.6）行为不变；已加回归测试 `tests/test_fusion.py::test_grade_cutoffs_stay_monotonic_for_tiny_calibrated_threshold`。
- 本报告 `thresholds` 由修复后函数重算并 round4：`{'high': 0.0348, 'mid_high': 0.0087, 'mid': 0.0043}`，可由 `python -m aidetect.calibrate report` 从 `mode_thresholds["balanced"]` 复现。

### 7. bench 交叉验证（`python -m aidetect.calibrate bench --limit 150`，wall-clock 566.1 秒）

| 模式 | 复评 Acc（JSON） | 复评 FPR（JSON） | 最大绝对差 | 结论 |
|---|---|---|---|---|
| strict | 0.9711（0.9711） | 0.0655（0.0655） | 0.0000 | 复现一致 |
| balanced | 0.9435（0.9435） | 0.1309（0.1309） | 0.0000 | 复现一致 |
| lenient | 0.9160（0.9146） | 0.1948（0.1980） | 0.0032 | 超 2e-3 容差 |

- 差异原因：`mode_thresholds.lenient=0.0042` 是 `round(0.00417869544056293, 4)` 的存储值，而标定时 `evaluation` 用未取整阈值计算；两者相差 2.1e-5，恰好跨过 2 个人类样本（FP 121→119，占 610 人的 0.0033）。用存储的 round4 阈值复算可 100% 复现 bench（Acc 0.9160 / FPR 0.1948 / FP 119）；strict/balanced 无样本翻转。
- 处理：属**阈值序列化的取整边界效应**，链路本身无错误；按要求**未修改 calibration.json 的系数/阈值/evaluation 去迎合 bench**，差异如实记录。
